**Read:** the wording ("Max-life fiber core", "Silver Ion Technology", "Zero thread seams") is lifted from
a specific vendor's catalog copy, which usually means the office already has an incumbent-style product in
mind and the RFQ will be brand-name-or-equal. Equal is achievable if #5, #8, and #11 are covered. The
capability statement already lists correctional/detention, fluid-resistant/waterproof, and sealed-cover
product lines, so this may be in range, but it is a different build from the Bldg 6578 innerspring unit.

**Go / no-go before pricing:**
1. Can we produce or source a welded (thread-free) sealed cover in royal-blue PU-coated nylon with silver
   ion? If only sewn sealed seams are available, the offer is non-compliant on #5 and #6.
2. Do we have a TB 129 report on a fiber-core, coated-nylon sealed mattress? If not, can the cover or core
   supplier furnish one for the exact combination?
3. Fiber core at 6–8": in-house or sourced?

If all three are yes → quote. If #1 or #2 is no → respond with the capability statement, state which
characteristics we meet, and offer the nearest compliant alternative (e.g., sewn-and-sealed cover) for
